## 3. File IO trace — `op_write_label` and `op_read_label`

### `image_path_to_label_path` (labeler.mbt:926–950)
- Splits `image_path` via `split_dir_name` → `(dir, basename)`.
- Splits `basename` via `split_stem_ext` → `(stem, ext)`.
- Splits `dir` → `(dir_parent, dir_leaf)`.
- **Path separator detection (l.931):** `let sep = if dir.contains("\\") { "\\" } else { "/" }` — ✓ detects backslash, otherwise forward slash.
- **In-folder fallback (l.932–936):** if `dir_leaf` does not start with `Image@`, `new_leaf = ""` — **the empty-branch is intact**, falling through to l.938–944 (`if new_leaf == ""`).
- **In-folder branch (l.938–944):**
  - if `dir == ""` → returns `label_basename` (just `stem + ".json"`),
  - else → `dir + sep + label_basename` (writes alongside the image). ✓
- Sibling branch (l.945–949) builds `Label@<rest>/<file>.json`.

### `video_path_to_label_path` (l.959–982)
- Same shape, swapping `Image@` for `Video@`. ✓
- In-folder fallback at l.971–976 also intact. ✓

### `op_write_label` (l.1035–1064)
```
1. derive is_video via dir_leaf prefix or extension sniff
2. label_path = video_path_to_label_path OR image_path_to_label_path
3. (label_dir, _) = split_dir_name(label_path)
4. if label_dir != "" → ensure_dir(label_dir) catch { _ => () }   ← L.1051–1055
5. @fs.write_file(label_path, req.content, create_mode=@fs.CreateOrTruncate) ← L.1060
6. return { image_path, label_path, bytes: req.content.length() }
```

- ✓ `ensure_dir` only runs when `label_dir != ""` — for the in-folder case (`dir + sep + label_basename`), `split_dir_name` returns `dir` as `label_dir` (not ""), so `ensure_dir` runs but is a no-op (the dir already exists).
- ✓ For the `Label@<rest>/` sibling case, `ensure_dir` creates the directory.
- ✓ `create_mode=@fs.CreateOrTruncate` — uses `CreateOrTruncate`, not `CreateNew` (the latter would fail on existing files). Comment at l.1056–1059 explicitly explains the choice and references the prior `CreateNew` regression.
- ✓ Backslash / forward slash separator preservation is handled inside `image_path_to_label_path` / `video_path_to_label_path` (sep variable), so `op_write_label` itself doesn't need to redo the check.

### `op_read_label` (l.986–1031)
- Same label-path derivation, then `if !@fs.exists(label_path)` returns `found: false`.
- Reads via `@fs.read_file(label_path) catch { _ => return found: false }`.
- Decodes via `data.text() catch { err => return found: true, content: "decode error: ..." }`.
- Returns `{ image_path, label_path, content, found: true/false }`. ✓

**IO trace: clean. No regression in this scope.**
